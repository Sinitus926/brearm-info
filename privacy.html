BREARM privacy policy

Last updated: 9 November 2026

What BREARM is

BREARM (BRE Attendance Roster Manager) is a desktop program that records attendance at a gaming community's TeamSpeak events and keeps the community's roster spreadsheets up to date. It runs on the user's own Windows PC.

Google data it accesses

  • Google Sheets: it reads and writes only the roster spreadsheets the user configures in the program (the community's attendance and member lists).
  • Google Drive: it reads and writes only the program's own shared database files in a folder the user chooses, and checks whether the signed-in account may open or edit the configured roster spreadsheets.

It does not read the user's email, contacts, calendar, or any other files.

Where data is kept

The Google sign-in token is stored only on the user's own PC. Attendance records are stored on the user's PC, in the configured roster spreadsheets, and in the shared Drive folder. No data is sent to the developer or to any other third party, nothing is sold, and nothing is used for advertising.

Removing access

Users can revoke BREARM's access at any time at myaccount.google.com/permissions, and delete its local data by deleting the program's BREARM_DATA folder.

Contact

Questions: use the support email shown on BREARM's Google sign-in screen.
